## Example scripts

| File | Description |
| --- | --- |
| `E1.m` | Unconstrained scalar quadratic optimization with CasADi and IPOPT |
| `E2.m` | Bounded nonlinear optimization of a sinusoidal objective |
| `E3.m` | Least-squares line fitting formulated as a nonlinear program |
| `E4.m` | Constrained quadratic optimization with inequality constraints |
| `E5.m` | Constrained box-volume maximization |
| `E6.m` | Finite-horizon mobile-robot optimal-control example using single shooting |

Requirements: MATLAB, CasADi, and IPOPT. Add CasADi to the MATLAB path before running the scripts.
