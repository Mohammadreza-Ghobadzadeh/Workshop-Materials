# Session 1 — Foundations of Numerical Optimal Control & CasADi

[Watch Session 1 on YouTube](https://youtu.be/L3QsqFfRAtQ?list=PLJ5BV5EDkg3s)

## Topics

- Optimal Control Problem formulation
- CasADi symbolic representations: SX, MX, and DM
- Computational graphs and algorithmic differentiation
- Jacobians, gradients, and Hessians
- CasADi Function objects
- Nonlinear root finding
- Numerical integration of ODEs with CVODES
- Differential-Algebraic Equations (DAEs) and IDAS integration
