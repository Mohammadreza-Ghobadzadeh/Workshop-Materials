# Session 1 — Workshop Overview & MPC Landscape

[Watch Session 1 on YouTube](https://youtu.be/2KobQZY-uXQ?list=PLUtae4hCv9Go)

## Overview

Session 1 introduces the overall structure of the workshop and positions Model Predictive Control within the broader numerical optimal-control framework.

## Topics Covered

- General Optimal Control Problem formulation
- Overview of dynamic programming, direct methods, and indirect methods
- Direct transcription from OCPs to finite-dimensional NLPs
- Motivation for Model Predictive Control
- Stability, computational load, recursive feasibility, and robustness
- Point stabilization and trajectory tracking
- Overview of Distributed MPC, Tube MPC, and Learning-Based MPC
- Optimization/modeling environments and the CasADi ecosystem
