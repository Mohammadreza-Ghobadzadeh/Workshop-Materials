# Session 2 — CasADi Foundations & Algorithmic Differentiation

[Watch Session 2 on YouTube](https://youtu.be/zn07UJtmqCQ?list=PLUtae4hCv9Go)

## Overview

Session 2 develops the computational foundations required for implementing optimization-based controllers efficiently with CasADi.

## Topics Covered

- Role and scope of CasADi in numerical optimization and optimal control
- Efficient symbolic computation
- Computational-graph representation
- Numerical, symbolic, and Algorithmic Differentiation
- Forward-mode and reverse-mode AD
- SX and MX representations in CasADi
- Function embedding and reusable computational blocks
