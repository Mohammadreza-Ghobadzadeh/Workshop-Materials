# Acknowledgements and Educational References

This Persian-language workshop was developed with reference to established educational material in numerical optimal control, Model Predictive Control, and CasADi.

## Systems Control and Optimization Laboratory (SysCOP), University of Freiburg

Educational material from Prof. Moritz Diehl and collaborators was an important reference for numerical optimal control, nonlinear programming, direct methods, and the broader computational framework underlying MPC.

Reference: https://www.syscop.de/

## Dr. Mohamed W. Mehrez

The workshop **"MPC and MHE implementation in MATLAB using CasADi"** was an important source of inspiration for hands-on CasADi/MATLAB implementation, particularly mobile-robot MPC and shooting-based formulations.

Videos: https://www.youtube.com/playlist?list=PLK8squHT_Uzej3UCUHjtOtm5X7pMFSgAL
Codes: https://github.com/MMehrez/MPC-and-MHE-implementation-in-MATLAB-using-Casadi

## CasADi Developers and Documentation

The official CasADi documentation, examples, and educational resources were used as foundational references for symbolic computation, computational graphs, Algorithmic Differentiation, numerical optimization, integration, and optimal-control implementation concepts.

Reference: https://web.casadi.org/docs/

## Numerical Optimal Control Workshop

Several prerequisite modules are intentionally not duplicated in this repository because they are already available in the companion Persian-language Numerical Optimal Control Workshop.

Repository: https://github.com/Hamzehkashi/Numerical-Optimal-Control-Workshop

The MPC workshop material was reorganized and presented in Persian with its own instructional structure, explanations, comparisons, and implementation workflow.

If any individual slide, figure, or code file is directly adapted from an external source, the original source and its applicable terms should also be consulted in addition to this repository-level acknowledgement.
